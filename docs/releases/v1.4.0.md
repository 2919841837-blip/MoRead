# MoRead · 墨知 1.4.0

## 中文

### 互动伴读与人物档案

- 伴读新增互动回答，可在对话中呈现原生控件、图表和可操作内容；支持调整生成方式、样式与图片生成策略。
- 人物提取改为先整理名单、再逐人补全档案，支持断点继续；完整扫描改进超时重试和截断结果恢复，并为主要人物补写小传。
- 人物页新增分组档案卡、人物详情与关系图；书籍资料任务通过前台通知和阅读页进度入口展示状态。
- 改进伴读消息、过程显示、脚注引用和输入区排版；默认聊天样式采用直接排版，保留角色自定义气泡。
- 段落讨论采用页边批注布局，支持就地调整划线样式与颜色。

### 阅读与书架

- 新增默认「纸墨」配色，改进浅色、深色及平板界面的文字层级和控件比例。
- 手机悬浮导航支持随书架滚动收起和展开，搜索从右侧入口展开；书架标签改用索引页签。
- 从书架续读卡或书籍详情继续阅读时，新增从封面翻开书的过渡动画。
- 目录新增章节长短节律条、分卷标记、快速定位刻度、当前章节提示和正倒序切换；目录、大纲、人物、书签共用导航弹层。
- 已生成的 AI 段评立即出现在正文、详情和回顾中，改进提前章节的段落生成调度。

### 修复与维护

- 修复 Android 上首条互动回复可能闪退的问题，改进选文与阅读页面状态管理。
- 改进 MDX 词典兼容，自带 RIPEMD-128 实现并移除 BouncyCastle 依赖。
- 启动时清理已安装版本的更新包，缓存占用按来源细分。
- 保留公开贡献的 TTS「恢复默认参数」功能及本地化、批注排版回归修复。

正式安装包：`mozhi-1.4.0-vc84.apk`，Android 8.0 及以上。使用正式发布证书，可覆盖安装已有正式版。数据库升级至版本 35，通过迁移保留现有数据。

## English

### Interactive companions and character dossiers

- Add interactive companion replies with native controls, charts, and actionable content. Configure generation, styling, and image generation policies.
- Extract character rosters before completing individual dossiers, with resumable progress. Improve full-scan retries and recovery of truncated results, and add biographies for major characters.
- Add grouped character cards, dossier pages, and relationship graphs. Show book-knowledge task progress through foreground notifications and a reader progress entry.
- Improve message layout, process displays, footnotes, and composition. Default conversations use inline text while preserving custom persona bubbles.
- Present passage discussions as margin annotations, with inline highlight-style and color editing.

### Reading and library

- Add the default Paper & Ink palette and refine light, dark, and tablet layouts.
- Collapse and expand the floating phone navigation while scrolling the bookshelf. Open search from its adjacent action and browse tags through index tabs.
- Add a cover-opening transition when continuing from the bookshelf or book details.
- Add chapter-length rhythm bars, volume labels, a quick-position scrubber, current-chapter cues, and reverse ordering to the contents panel. Contents, outlines, characters, and bookmarks share the navigation sheet.
- Show generated AI annotations immediately in the reader, details, and review. Improve paragraph scheduling for upcoming chapters.

### Fixes and maintenance

- Fix a possible Android crash on the first interactive reply and improve text selection and reader state management.
- Improve MDX compatibility with a built-in RIPEMD-128 implementation and remove BouncyCastle.
- Clean up update packages for installed versions at startup and break down cache usage by source.
- Preserve the contributed TTS reset-to-defaults control, localized labels, and annotation-layout regression fixes.

Official package: `mozhi-1.4.0-vc84.apk`, for Android 8.0 or later. Signed with the official release certificate for upgrades from existing official installations. Database version 35 includes migrations preserving existing data.
